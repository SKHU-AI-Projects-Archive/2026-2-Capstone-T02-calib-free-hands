# CalibFreeHands 카메라 연결 테스트

휴대폰의 브라우저에서 영상을 송신하고, PC 브라우저에서 두 입력을 연결해 전환하는 테스트입니다. 휴대폰에 별도 앱을 설치할 필요가 없습니다. 영상은 WebRTC로 브라우저 사이에서 전달됩니다. Python 서버는 연결 정보와 카메라 진단 결과를 중계합니다. 보정과 녹화, WiLoR, 3D 표시 기능은 발표용 Windows 앱에서 구현할 항목입니다.

## PC 한 대에서 확인

Python 3.10 이상에서 압축을 푼 폴더를 열고 실행합니다. 추가 Python 패키지는 필요 없습니다.

```powershell
python .\probe.py
```

1. 출력된 `PC` 주소를 브라우저에서 먼저 엽니다.
2. 출력된 `Camera A`와 `Camera B` 주소를 각각 별도 탭에서 엽니다. 각 탭에서 **카메라 연결**을 누르고 브라우저 카메라 권한을 허용합니다. 동시에 두 탭에서 같은 물리 카메라를 사용할 수 있는지는 PC 환경에 따라 다릅니다.
3. PC 화면에서 A와 B를 클릭합니다. PowerShell에서 `Ctrl+C`를 누르면 서버가 종료됩니다.

## Galaxy와 iPhone에서 확인

1. PC와 두 휴대폰을 서로 통신할 수 있는 동일한 공유기 또는 PC 핫스팟에 연결합니다. 공용 Wi-Fi는 접속 기기 간 통신이 제한될 수 있습니다.
2. 세 기기에서 열 수 있는 **신뢰된 HTTPS 주소**를 준비합니다. 도메인 없이 Windows 핫스팟의 IPv4 주소로 실행할 수 있습니다. 아래의 `192.168.137.1`은 예시입니다. 새 PC에서 실제 핫스팟 IP를 확인하고, 해당 IP가 인증서의 SAN에 포함되도록 발급합니다. 서버 인증서와 개인 키는 PEM 형식입니다. 로컬 CA를 사용하면 PC와 휴대폰에서 그 CA의 공개 인증서를 신뢰해야 합니다. iPhone에서는 설치 후 인증서 신뢰 설정에서도 신뢰를 켭니다.

   ```powershell
   python .\probe.py --bind 192.168.137.1 --origin https://192.168.137.1:8765 --cert .\server.pem --key .\server.key
   ```

   Windows 방화벽에서 테스트용 사설 네트워크의 TCP 8765와 WebRTC의 기기 간 UDP 통신이 허용되어야 합니다. `http://PC의내부IP:8765`는 휴대폰 카메라 접근에 필요한 보안 컨텍스트를 만들 수 없습니다. 출력된 주소는 해당 테스트에 참여하는 기기에서만 사용합니다.

3. PC에서 `PC` 주소를 먼저 열고, Galaxy Chrome에서 `Camera A`, iPhone Safari에서 `Camera B`를 엽니다. 카메라 권한을 허용하고 PC에서 전환합니다. 두 휴대폰의 브라우저와 화면을 켜 둡니다.
4. 연결하면 1080p를 우선 요청하고 초점·노출·화이트밸런스의 수동 모드를 자동으로 시험합니다. PC 수신 화면에 휴대폰 캡처 해상도, 실제 수신 해상도, 수동 모드 요청 결과와 약 2초 간격으로 두 번 읽은 설정이 표시됩니다. 실제 잠금을 검증하려면 가까운 물체와 먼 배경을 번갈아 비추고, 조명의 밝기와 색온도를 바꾸면서 초점·밝기·색의 반응을 확인합니다. 송신 화면에서 **잠금 다시 시험**을 눌러 결과를 갱신할 수 있습니다. 다시 연결하면 시험 설정이 초기화됩니다.

이 테스트는 STUN/TURN 서버를 사용하지 않습니다. 휴대폰을 열어 둔 상태에서 PC 탭이 새로고침되면 휴대폰의 **연결 끊기 → 카메라 연결**을 다시 누릅니다. 실제 스마트폰 지원 여부, 방송 화질과 지연 시간은 발표에 쓸 기기와 네트워크에서 확인해야 합니다.
