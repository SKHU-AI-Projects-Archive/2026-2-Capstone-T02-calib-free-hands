# HandCalib 손 영상 촬영 가이드 (요약본)

지도교수가 준 `TalkFile_handcalib_guide.html`(2026-11-14 작성)의 내용을 옮겨 둔 문서입니다. 원본 HTML은 더 이상 보관하지 않습니다.

- calibrator.py와 check_session.py 코드는 원문 그대로 이 폴더에 있습니다.
- 화면에 띄울 체커보드는 checkerboard_8x8.html과 checkerboard_8x8.svg입니다.
- 규약의 수치(20초, 45°, 3%, 세션 수)는 지금까지의 실험으로 정한 권장값이며, 지도교수의 안내에 따라 바뀔 수 있습니다.

연구 목표는 손을 찍은 영상만으로 카메라의 초점거리 f를 추정하는 것입니다. 세션 하나는 카메라 설정 하나에 체커보드 영상 2개와 손 영상 8개로 이루어집니다.

## 0. 핵심 규칙 8가지

1. 오른손 하나만 찍고, 손바닥이 카메라를 향하게 합니다.
2. 정면 자세에서 시작하고, 기울기는 45°까지만 줍니다.
3. 천천히 움직입니다. 한쪽으로 기울였다가 정면으로 돌아오는 데 3초 이상 씁니다.
4. 영상 하나는 20초 이상 찍습니다.
5. 손목부터 손끝까지 항상 화면 안에 둡니다. 손 길이는 화면 짧은 변의 1/3 이상입니다.
6. 카메라를 고정합니다. 줌, 초점, 노출을 잠그고 손떨림 보정을 끕니다.
7. 카메라 설정을 바꿀 때마다 체커보드를 다시 찍습니다.
8. 원본 파일 그대로 제출합니다. 메신저로 보내거나 편집한 파일은 쓸 수 없습니다.

## 1. 세션 순서

세션은 "기기 하나와 카메라 설정 하나"입니다. 설정이 하나라도 바뀌면 새 세션입니다.

1. 카메라를 거치대에 고정하고 설정을 잠급니다.
2. `checkerboard_before`를 찍습니다.
3. 손 영상을 찍습니다. 동작 4가지를 2번씩, 모두 8개입니다.
4. `checkerboard_after`를 찍습니다.
5. 파일을 옮겨 이름을 바꾸고 session.json을 씁니다.
6. calibrator.py로 참값을 재고 손 영상을 점검합니다.

권장 분량은 한 사람당 기기 2대 이상, 기기마다 설정 3가지 이상으로 세션 6개 이상입니다.

## 2. 카메라 설정

f가 서로 다른 카메라에서도 방법이 통하는지 봐야 하므로 설정을 일부러 다양하게 잡습니다. f는 픽셀 단위라서 렌즈뿐 아니라 해상도에 따라서도 달라집니다.

| 바꿀 것 | 예 | f에 미치는 영향 |
|---|---|---|
| 렌즈 배율 | 0.5x, 1x, 2x, 3x, 5x | 배율이 클수록 f가 커짐 |
| 해상도 | 720p, 1080p, 4K | 같은 렌즈라면 4K의 f는 1080p의 약 2배 |
| 디지털 줌 | 1.5x, 2.5x | 확대한 만큼 f가 커짐. 세션 중에는 바꾸지 않음 |
| 기기 | 여러 기종의 스마트폰, 태블릿, 노트북 웹캠, USB 웹캠, 미러리스 | 센서와 렌즈가 달라 f가 다름 |

지금까지 잰 값은 1080p 기준으로 0.5x 렌즈가 약 880 px, 1x 렌즈가 약 1550~1680 px입니다. 이 범위 밖의 값이 많이 필요합니다.

세션 동안 고정할 것:

- 줌은 세션을 시작한 뒤 건드리지 않습니다.
- 초점과 노출은 화면을 길게 눌러 잠급니다(AE/AF 잠금). 초점이 바뀌면 f도 1% 안팎으로 달라집니다.
- 손떨림 보정, 액션 모드, 시네마틱 모드, HDR을 모두 끕니다.
- 카메라는 삼각대나 거치대에 고정하고, 가로로 찍습니다.

피할 것:

- 어안 렌즈나 보정을 끈 액션캠처럼 직선이 휘어 보이는 카메라는 쓰지 않습니다. calibrator는 렌즈 왜곡이 없다고 가정합니다.
- 전면 카메라를 쓸 때는 "좌우 반전 저장"을 끕니다. 반전되면 오른손이 왼손으로 찍혀 처리되지 않습니다.

## 3. 체커보드로 참값 재기

### 보드

- 칸이 8×8인 보드를 씁니다. 내부 모서리는 7×7로, calibrator 기본값과 같습니다.
- 가장 쉬운 방법은 `checkerboard_8x8.html`을 태블릿이나 모니터에 전체 화면으로 띄우고 밝기를 중간으로 맞추는 것입니다.
- 인쇄해서 쓸 때는 딱딱한 판에 붙이고, 칸의 가로와 세로를 자로 재서 같은지 확인합니다.
- 칸이 정사각형이 아니면 참값이 틀어집니다. 가로가 3.5% 짧은 보드 때문에 f가 약 6% 크게 나온 적이 있습니다.

### 촬영

- 손 영상과 같은 설정, 같은 거리에서 찍습니다.
- 보드가 화면의 절반 이상을 차지하고, 보드 전체가 항상 화면 안에 있어야 합니다.
- 정면에서 시작해 위, 아래, 왼쪽, 오른쪽으로 30~45°씩 천천히 기울입니다.
- 20초 이상 찍습니다. 화면에 조명이 비쳐 칸이 하얗게 날아가지 않게 합니다.
- 세션의 처음과 끝에 한 번씩, 모두 2개를 찍습니다.

### 계산

```bash
python -c "from calibrator import Calibrator; print(Calibrator('checkerboard', (7, 7)).run('checkerboard_before.mov'))"
```

- 두 값을 f_before와 f_after에, 평균을 reference_f에 적습니다. 이 작업은 `measure_reference.py --write`가 대신합니다.
- 두 값이 3% 넘게 다르면 세션 도중 설정이 바뀐 것이므로 세션을 처음부터 다시 찍습니다.

## 4. 손 영상 공통 규약

### 손

- 오른손만 화면에 넣습니다. 왼손, 다른 사람의 손, 얼굴이 들어오지 않게 합니다. calibrator는 오른손 관절만 읽습니다.
- 손가락을 자연스럽게 펴고, 찍는 동안 손가락 모양을 바꾸지 않습니다. 엄지를 접거나 손가락을 오므리지 않습니다.
- 손바닥이 카메라를 향하게 하고, 손은 책상에 붙이지 않고 공중에 듭니다.

### 자세

- 정면 자세로 2초 멈췄다가 시작하고, 동작 사이사이에도 정면을 지나갑니다.
- 기울기는 최대 45°입니다. 손이 얇은 선처럼 보일 만큼 돌리면 관절 검출이 깨집니다.
- 정면에 가까운 프레임이 없던 영상은 50개 중 9개만 오차 10% 안에 들었습니다. 있던 영상은 66개 중 33개였습니다.

### 속도와 길이

- 한쪽으로 기울였다가 정면으로 돌아오는 데 3초 이상 씁니다. 손이 조금이라도 흐려 보이면 너무 빠른 것입니다.
- 영상 하나는 20초 이상이고, 왕복 동작을 3번 이상 반복합니다.
- 잘 된 영상은 손이 프레임마다 손 길이의 1% 정도씩 움직였습니다. 빠르게 흔든 영상은 20%씩 움직였고 대부분 실패했습니다.

### 위치와 크기

- 손목부터 손끝까지 항상 화면 안에 두고, 가장자리에 손가락 한 마디 정도 여유를 둡니다.
- 손 길이가 화면 짧은 변의 1/3에서 1/2 사이가 되게 하고, 손은 화면 가운데 근처에 둡니다.
- 손이 작게 찍힌 영상은 크게 찍힌 영상보다 오차가 2배 넘게 컸습니다.

### 환경

- 밝은 곳에서 찍습니다. 어두우면 셔터가 느려져 흐려집니다.
- 창문이나 조명을 등지지 않고, 배경은 단순할수록 좋습니다.

## 5. 동작 4가지

세션마다 네 동작을 2번씩 찍습니다.

| 파일 | 동작 | 방법 |
|---|---|---|
| hand_twinkle_01, _02 | 반짝반짝 | 팔뚝을 축으로 손바닥을 왼쪽 45°, 정면, 오른쪽 45°, 정면 순으로 돌립니다. 한 번에 6초쯤 걸리고 3번 이상 합니다. |
| hand_nod_01, _02 | 끄덕끄덕 | 손끝을 카메라 쪽으로 40° 숙였다가 정면, 뒤로 40° 젖혔다가 정면으로 옵니다. 팔 전체를 같이 움직이고, 한 번에 6초쯤 걸리며 3번 이상 합니다. |
| hand_circle_01, _02 | 접시 돌리기 | 30° 정도 기울인 채 기울어진 방향을 위, 오른쪽, 아래, 왼쪽 순으로 돌립니다. 한 바퀴에 7초쯤 걸리고, 정면에서 시작해 3바퀴 돈 뒤 정면으로 끝냅니다. |
| hand_mix_01, _02 | 섞기 | 반짝반짝 1번, 끄덕끄덕 1번, 접시 돌리기 1바퀴를 이어서 하고, 동작이 바뀔 때마다 정면에서 잠깐 멈춥니다. 20초 이상이 되도록 반복해도 됩니다. |

하지 않는 동작은 손을 흔드는 인사, 주먹 쥐었다 펴기, 손가락 접기, 책상에 손을 붙이고 돌리기입니다. 이런 동작은 손 모양이 변하거나 정면 자세가 나오지 않습니다.

## 6. 폴더와 파일명

```
handcalib_data/
├── s01_20261120_iphone13_1x_1080p/
│   ├── session.json
│   ├── checkerboard_before.mov
│   ├── checkerboard_after.mov
│   ├── hand_twinkle_01.mov, hand_twinkle_02.mov
│   ├── hand_nod_01.mov, hand_nod_02.mov
│   ├── hand_circle_01.mov, hand_circle_02.mov
│   └── hand_mix_01.mov, hand_mix_02.mov
└── s02_20261121_galaxys23_05x_1080p/
```

이름 규칙:

- 세션 폴더 이름은 `수집자_날짜_기기_렌즈_해상도`입니다.
  - 수집자 ID(s01, s02 …)는 지도교수가 배정합니다.
  - 디지털 줌은 끝에 붙입니다. 예: `..._1x_1080p_zoom15`
- 손 영상 이름은 `hand_동작_번호`입니다. 동작은 twinkle, nod, circle, mix 중 하나이고 번호는 두 자리입니다.
- 체커보드 영상 이름은 `checkerboard_before`와 `checkerboard_after`입니다.
- 이름에는 영문 소문자, 숫자, 밑줄만 씁니다. 한글, 공백, 괄호, "복사본"은 쓰지 않습니다.
- 확장자는 카메라가 만든 그대로(.mov, .mp4) 둡니다.
- 다시 찍을 때는 잘못 찍은 파일을 지우고 같은 이름으로 저장합니다.

session.json 항목은 `session_template.json`에 있습니다.

| 항목 | 내용 |
|---|---|
| collector | 수집자 ID |
| date | 촬영 날짜 |
| device | 기기 |
| camera | rear 또는 front |
| lens | 렌즈 배율 |
| digital_zoom | 디지털 줌 배율 |
| resolution | [가로, 세로] |
| fps | 프레임률 |
| stabilization | "off" |
| focus_exposure_locked | true |
| checkerboard | squares [8, 8], inner_corners [7, 7], shown_on, f_before, f_after |
| reference_f | f_before와 f_after의 평균 |
| videos | 손 영상마다 file, motion, f(점검 값), note |
| notes | 조명, 배경 등 |

- collector는 폴더 이름 맨 앞의 수집자 ID와 같아야 합니다.
- videos에는 세션의 손 영상을 모두 적습니다.

파일 옮기기:

- 케이블, AirDrop, 또는 클라우드의 "원본 화질"로 옮깁니다.
- 메신저로 보내면 해상도가 줄어 f가 달라지므로 그런 파일은 쓸 수 없습니다.
- 자르기, 회전, 필터, 재인코딩을 하지 않습니다.

## 7. calibrator.py

- 설치(원문 기준): `pip install rtmlib onnxruntime opencv-python numpy`
  - GPU가 있으면 onnxruntime 대신 onnxruntime-gpu를 설치합니다.
  - GPU가 없으면 코드의 `device="cuda"`를 `device="cpu"`로 바꿉니다. 이 경우 영상 하나에 몇 분 걸립니다.
- 원문의 확인된 환경은 Python 3.8, rtmlib 0.0.15, onnxruntime-gpu 1.19.2, opencv-python 5.0.0, numpy 1.24.4입니다.
- 이 서버에서 쓰는 환경은 `requirements.txt`에 있습니다.

사용법:

- 체커보드 참값: `Calibrator("checkerboard", (7, 7)).run("checkerboard_before.mov")`
- 손 영상 f 추정: `Calibrator("hand").run("hand_twinkle_01.mov")`
- 세션 일괄 점검: `python check_session.py <세션 폴더> <참값 f>`

원문에 실린 예시 출력은 기존 영상 2개, 참값 1680으로 낸 것입니다.

| 영상 | f | 오차 |
|---|---|---|
| hand_nod_01 | 1685 | +0.3% |
| hand_twinkle_01 | 1669 | -0.6% |

## 8. 제출 전 점검

오차가 크다는 이유로 영상을 지우거나 다시 찍지 않습니다. 지금 방법은 규약에 가까운 영상에서도 절반 정도만 오차 10% 안에 들기 때문에, 잘 나온 영상만 고르면 연구 결과가 왜곡됩니다. 다시 찍는 이유는 아래의 규약 위반뿐입니다.

영상마다 눈으로 확인할 것:

- 오른손 하나만 보이고, 손가락 모양이 처음부터 끝까지 같다.
- 정면 자세로 시작하고, 손이 선처럼 보이는 순간이 없다.
- 멈춰서 본 어느 장면에서도 손이 흐리지 않다.
- 손목부터 손끝까지 한 번도 화면 밖으로 나가지 않았다.
- 손 길이가 화면 짧은 변의 1/3 이상이다.
- 길이가 20초 이상이다.

세션마다 확인할 것:

- 체커보드 영상 2개의 f 차이가 3% 이내다.
- 손 영상이 8개이고 이름이 규칙과 같다.
- session.json의 모든 항목을 채웠다.
- 파일이 원본 그대로이고, 해상도가 촬영 설정과 같다.
- 영상에 얼굴이나 다른 사람이 찍히지 않았다.

다시 찍는 경우:

- 위 "영상마다 눈으로 확인할 것" 중 하나라도 어긴 영상
- calibrator.py가 오류로 끝나는 영상 (손이 거의 검출되지 않은 경우)
- 체커보드 두 값이 3% 넘게 다른 세션 (세션 전체)

제출하는 폴더에는 규약을 지킨 영상만 남깁니다.
