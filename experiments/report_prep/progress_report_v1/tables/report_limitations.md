# Limitations

Each limitation states what has already been done about it, so the section reads as an audit rather than an apology.

| limitation | impact | what is already mitigated | what remains | when to resolve | evidence level |
|---|---|---|---|---|---|
| Single GigaHands rig | every camera result comes from one capture setup, one optics family, one resolution and one distortion regime | 175 views over 40 physical cameras and 5 sequences; results re-checked with camera- and sequence-level clustering | no evidence that any number transfers to another rig | final confirmatory holdout | PENDING_EXTERNAL_CONFIRMATION |
| Provided 3D is not an independent external ground truth | CAM-EXP-001.3's ~4 mm figure is self-consistency between the released 2D and the provided 3D | reconstruction never used the provided 3D as an input; a wrong-hand control is reported alongside | absolute hand accuracy is unknown | only with a dataset carrying independent metric GT | OPEN_ISSUE |
| CAM-EXP-002 is focal-only | the sensitivity result covers focal length and absolute depth, not principal point, anisotropic focal or distortion | the scope is stated explicitly wherever the number appears | either narrow the paper claim, or run CAM-EXP-002.1 | before any broad intrinsic-sensitivity claim | OPEN_ISSUE |
| GeoCalib is not run-to-run deterministic | any GeoCalib-derived number carries a ~+/-0.35 pp run-to-run tolerance that no bootstrap captures | quantified (40 frames x 3 repeats), the input was verified bit-identical, and an independent full re-run is reported | try deterministic algorithms; otherwise report the median of k repeats | before any headline number goes into a paper | OPEN_ISSUE |
| E2 is a selection-set number | 6.14 % was obtained by picking the best of five candidates on the same views it is reported on | E2 frozen to a spec file; LOSO shows the selection is stable (5/5) and gives a held-out range | a genuinely independent number | final confirmatory holdout | EXPLORATORY_INTERNAL_VALIDATION |
| AnyCam end-to-end inference unavailable on Windows | the behavioural question - what does it emit on static clips - is unanswered | the mechanism was tested on AnyCam's own unmodified scoring function; the blocker is documented in full | run the kept driver script on Linux | if a Linux environment becomes available | OPEN_ISSUE |
| External confirmation not yet performed | no claim has been tested on data that did not influence it | InterHand2.6M reserved as the primary sealed holdout, contamination risk zero; HanCo reserved for single-frame claims only | a user decision on downloading the image releases | after CAM-EXP-005/006, once | PENDING_EXTERNAL_CONFIRMATION |
| Hand QC thresholds not manually validated | false-pass / false-exclude rates of the automatic QC are unknown | no camera result uses the hand QC at all | human adjudication of 100-300 stratified observations | before CAM-EXP-006 (hand-aware calibration) | OPEN_ISSUE |
| Saturation is demonstrated only up to 64 frames | says nothing about hundreds of frames | measured rather than predicted, on all 175 views, in one run | nothing planned - the curve never descended, so a larger N is not a promising lever | not planned | ROBUST_BUT_SINGLE_DATASET |
